网站测速工具怎么选？不要只盯着一个 100 分

测速工具适合定位性能问题，但分数只是诊断信号。判断网站快不快，应该把真实用户体验、实验室测试、服务器响应和业务功能一起看。

PageSpeed Insights 更适合先看 Google 视角

PSI 会把可用的真实用户体验数据和 Lighthouse 实验室测试放在一起，适合检查 Core Web Vitals 和常见前端性能问题。看报告时要先分清两类数据，而不是只看顶部评分。

GTmetrix 更适合反复测试具体页面

GTmetrix 适合从指定测试环境观察瀑布图、资源加载顺序和页面体积。它可以帮助定位哪张图片、哪个脚本或第三方请求拖慢页面，但测试节点与真实访客环境仍可能不同。

真正该优先修什么

优先处理用户能直接感受到的问题：首屏主要内容很晚才出现、点击后长时间无响应、布局突然跳动、图片和脚本体积明显过大。为了从 96 分追到 100 分而牺牲必要功能，通常不划算。

上线后还要看真实数据

一次本地测试不能代表不同国家、网络和设备。对有稳定访问量的网站，应结合真实用户数据和业务转化观察长期趋势。
