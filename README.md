# 迈引导航（Mayin Tools）

迈引导航是一个面向中文用户的工具导航与实用指南站，整理跨境办公、内容创作、网站运营、开发协作和出海业务中常用的在线服务与软件。

**网站地址：<https://mayin-tools.github.io/>**

我们希望帮助用户更快判断：**这个工具是做什么的、适不适合当前任务、从哪里开始，以及使用时有哪些需要留意的地方。**

## 可以找到什么

站点覆盖 AI 与智能办公、翻译与写作、设计与图片、视频与字幕、音频与语音、建站与 CMS、开发与 API、域名与安全、项目协作、远程办公、文档与 PDF、云存储、数据与 SEO、营销以及电商客服等常见场景。

除了工具入口，还整理了工具对比、选择建议和实际操作指南，适合在“不确定该选哪个工具”或“知道工具但不知道怎么开始”时使用。

## 内容方式

工具页尽量先回答真实用途和适用场景，再提供官方网站入口。涉及价格、许可、系统支持、隐私和产品能力等可能变化的信息，请以对应官方网站当前页面为准。

工具被本站收录不代表对其安全性、服务质量或长期可用性作出保证。使用涉及客户数据、付款、合同或其他重要业务的第三方服务前，建议自行查看其正式条款和隐私政策。

## 实用指南

站内提供任务型指南，例如 AI 写作工具选择、独立站建站工具比较、SEO 工具分工、PDF 压缩、Google 收录排查、网站测速，以及 ChatGPT / Claude、Shopify / WooCommerce 等常见工具对比。

可从 [实用指南](https://mayin-tools.github.io/guides/) 查看完整内容。

## 搜索与收藏

站点支持按工具名称、用途、分类和常见任务词搜索。收藏信息保存在当前浏览器中；工具页的“官方网站”按钮会打开对应第三方网站。

## 隐私与统计

站内搜索和收藏主要在浏览器本地运行。Google Analytics 仅在访客主动同意后加载，统计设置可以随时从网站页脚重新选择。

更多信息请查看 [隐私政策](https://mayin-tools.github.io/privacy/)。

## 广告

部分页面可能展示明确标注的广告。点击广告后将前往第三方网站。

## 反馈

如果发现链接失效、产品名称变化、页面描述有误或官方网站地址需要调整，可以通过仓库 Issues 反馈。
