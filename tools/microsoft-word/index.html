文档与 PDF

Microsoft Word 怎么用更高效？别把所有问题都当成“排版问题”

Microsoft Word 最容易低估的能力不是“能打字”，而是长文档结构、样式、审阅和多人协作。真正高效的做法，是把格式规则交给样式，把页面差异交给分节，而不是手动逐段调字号和空格。

长文档先用样式，不要手工逐段格式化

标题 1、标题 2、正文、引用等样式能统一字体、间距和目录结构。后续整体调整时改一次样式就够，也能让导航窗格和自动目录正常工作。

页眉页脚和横向页面要用分节

论文、合同、报告里经常需要某一页横向、不同页码或不同页眉。正确工具通常是“分节符”，而不是反复插空行或把内容硬推到下一页。

多人修改时优先用修订和批注

需要审核的文档不要靠“改成红色字体”传递意见。修订可以保留增删记录，批注适合讨论具体问题；正式定稿前再统一接受或拒绝修改。

跨版本和跨软件交付要检查兼容性

复杂字体、文本框、域、公式和表格在不同版本 Word、网页版或其他办公软件中可能有差异。重要文件在交付前最好用目标环境打开一次，或同时提供 PDF 定稿版。

共享链接和附件是两种不同工作流

发附件适合冻结某个版本；共享云端文档适合多人持续协作。团队要明确哪一个才是“主版本”，否则邮箱附件和云端文件很容易并行分叉。

长文档最怕“看起来一样，实际上不是同一种格式”。 手工加粗、手工调字号能暂时把页面做漂亮，但目录、编号、页眉和后续批量修改都会越来越难维护。正式文档尽量用样式控制标题层级，用分节处理页面差异，并在交付前通过导航窗格检查标题结构，而不是只从第一页往后肉眼翻。

长文档效率低，通常不是因为不会某个按钮，而是没有把“内容结构”和“视觉格式”分开。先用标题样式建立层级，再用分节控制页眉页脚和编号，最后统一目录、引用和图表编号，会比逐段手调字体稳定得多。多人协作时，也尽量避免互相复制带格式文本；复杂文档最怕局部格式越来越多，最终谁也说不清某一段为什么长得不一样。
