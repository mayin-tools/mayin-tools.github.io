域名、网络与安全

Cloudflare 是什么？改 DNS 前先弄清它会影响什么

Cloudflare 提供 DNS、CDN、安全、边缘计算和网站性能相关服务。它位于域名和网站访问链路的重要位置，所以任何 DNS 或代理设置都应以“可回退”为前提。

访问 Cloudflare 官方网站 ↗将打开 cloudflare.com

第三方工具入口，本站与 Cloudflare 运营方无隶属关系。

Cloudflare 常见用途有哪些

最常见的入口是 DNS 管理和代理加速。启用更多安全或缓存功能前，先确认源站、证书和现有重定向正常，避免一次修改太多导致问题难定位。

接入网站前先备份 DNS 记录

在 cloudflare.com 添加站点前先导出现有 DNS 记录，并确认网站和邮箱分别依赖哪些记录。接入后逐项验证首页、HTTPS、登录、API 和邮件解析。

哪些配置可能让网站直接打不开

错误 DNS、SSL 或缓存配置可能影响全站访问，甚至同时影响邮箱。生产站修改前应保留原设置和回退方案，并避免泄露源站或密钥。

什么时候只用 DNS、什么时候加代理

如果只需要域名注册或简单 DNS，可以直接比较注册商提供的服务；需要 CDN、安全和边缘能力时再评估 Cloudflare 的完整产品。

Porkbun以域名注册和管理为主的服务商。Dynadot面向域名注册、转入、管理和交易的服务商。Akamai提供内容分发、云计算和网络安全服务的平台。
